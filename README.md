# T1_POA

Repositório para desenvolvimento do T1 de Projeto e Otimização de Algoritmos.

## Sobre

Trabalho sobre o problema da Maior Subsequência Comum (LCS - Longest Common
Subsequence) entre duas strings, resolvido com Programação Dinâmica.

## Estrutura

- `src/LCSBruteForce.java`: implementação recursiva (força bruta) do LCS,
  com contagem de iterações (chamadas recursivas) e medição do tempo de
  execução de cada teste.

## Como compilar e executar

```bash
cd src
javac LCSBruteForce.java
java LCSBruteForce
```

O programa executa alguns casos de teste pré-definidos e, ao final, permite
digitar duas strings próprias para testar.
